# 77PLAY 玩聚空間桌遊會員系統

一個用於管理會員資料與儲值紀錄的簡易後台系統

#### 使用者登入
- 透過帳號密碼登入系統
#### 客戶清單管理
- 查看所有會員
- 顯示到期日與狀態
- 支援搜尋客戶
- 可編輯或刪除客戶資料
#### 新增客戶
- 建立新會員
- 設定金額與加入日期
#### 客戶資料管理
- 查看會員基本資料
- 顯示目前餘額與到期日
- 支援修改會員LINE ID
#### 儲值與消費紀錄
- 記錄每筆操作
- 自動計算餘額與剩餘次數
- 可依日期範圍查詢歷史紀錄
